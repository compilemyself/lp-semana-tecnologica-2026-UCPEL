# Semana Tecnológica UCPel 2026

Landing page da Semana Tecnológica da Universidade Católica de Pelotas (UCPel), desenvolvida como Projeto Integrador IV-A nas disciplinas de Engenharia de Software e Ferramentas de Desenvolvimento Web.

O projeto foi desenvolvido com HTML5, CSS3 e JavaScript, sem utilização de framework de front-end.

## Tecnologias

* HTML5
* CSS3
* JavaScript
* Google Maps Embed API
* YouTube
* Google Forms
* Git e GitHub
* GitHub Pages

HTML concentra a estrutura da página, CSS cuida da identidade visual, layout e responsividade, e JavaScript é responsável pelas interações e partes dinâmicas da interface.

## Estrutura de pastas do projeto

```text
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── img/
    ├── hero/
    ├── logo/
    ├── oficinas/
    └── palestrantes/
```

A pasta `img` reúne os assets utilizados na página. Os arquivos `index.html`, `style.css` e `script.js` concentram a maior parte da implementação.

## Conteúdo

A página já possui a estrutura principal do evento, incluindo apresentação, programação, palestrantes, oficinas, localização e inscrição, oganizados de maneira estratégia
e prezando boas práticas de organização da informação.

Algumas informações ainda estão como conteúdo provisório, principalmente textos, nomes, imagens, atividades e contatos. A substituição desses dados pode ser feita sem alterar a estrutura principal da aplicação.

## Integrações

A página utiliza alguns serviços externos para complementar o conteúdo:

Google Maps Embed API, para exibição da localização do evento;
YouTube, para o vídeo incorporado na seção Sobre;
Google Forms, para o formulário de inscrição.

## Desenvolvimento local

Para executar o projeto localmente, pode ser utilizado um servidor HTTP como o Live Server do Visual Studio Code.

## Publicação

O projeto está publicado no GitHub Pages como uma página estática.

O repositório também funciona como parte da documentação da implementação, permitindo consultar diretamente os arquivos HTML, CSS e JavaScript utilizados no desenvolvimento.
