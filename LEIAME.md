# Semana Tecnológica UCPel 2026

Aplicação web estática desenvolvida como **Projeto Integrador IV-A**, para a Semana Tecnológica da Universidade Católica de Pelotas (UCPel)

O projeto contempla as disciplinas **Engenharia de Software** e **Ferramentas de Desenvolvimento Web**, aplicando boas práticas de desenvolvimento, organização da informação, usabilidade, acessibilidade e responsividade.
